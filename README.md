# MediaTracker

An application in which you can track Movies and TV shows and see where they are currently streaming. Made 100% by AI with Github Copilot and Chat GPT-5

## Getting Started

You can use this by going to https://maxpaxio.github.io/MediaTracker. it supports syncing via Google Drive and WebDav.
